Getting started

MCP allows applications and AI clients to communicate with hardware through Serial Flux. The client launches the MCP executable automatically using STDIO. Do not start it manually. MCP Inspector is optional and intended for testing.

  1. Open a compatible Serial Flux release.
  2. Choose Tools → MCP Server Settings and enable MCP.
  3. Keep read-only mode unless a trusted client needs hardware control.
  4. Configure the client with the executable path below.

API reference
ToolArgumentsPurpose
Connection IDs accept a unique ID or case-insensitive name with a compatible SF bridge. Duplicate names require the unique ID. Send accepts ASCII, HEX or space-separated 8-bit binary groups; maximum 4096 bytes. No implicit newline. Receive is a non-destructive snapshot of the oldest buffered bytes, up to a 64 KiB buffer per connection.
Example send (JSON arguments)
{"id":"Default","data":"version ?\r\n","format":"ascii"}
Use a command supported by your firmware. JSON escapes become actual control characters when parsed; typing literal backslash sequences into a plain text field does not convert them in this release. Alternatively use HEX: 76 65 72 73 69 6F 6E 20 3F 0D 0A.


Project management
Enable project management and/or project saving separately in SF MCP settings. Saving requires a valid SF save entitlement. Project open disconnects existing connections. New and close reset to an untitled workspace using SF New behavior (connection settings retained).
  • sf_project_info: {} — path, modified status and counts
  • sf_project_list_recent: {} — recent paths
  • sf_project_open: path, optional unsaved_changes
  • sf_project_save: {} — save current named project
  • sf_project_save_as: path, optional overwrite (false by default)
  • sf_project_new, sf_project_close, sf_project_reload: optional unsaved_changes (reject by default, save or discard)
Use full .sflux paths. Stop running Python scripts before project changes. Modified detection compares saved project content, excluding layout and group expansion.
Troubleshooting and security
If the bridge is disconnected, check SF is running under the same Windows account, MCP is enabled, and SF is compatible. Use sf_server_info and sf_list_connections first. For hardware operations enable hardware control only for trusted clients. Do not automatically retry timed-out writes. Close all MCP clients before upgrading or uninstalling. No network port is needed.
