# Version history

## 0.1.9 — TCP and UDP connection management (2026-11-24)
- Extend existing connection tools to create and configure TCP Client, TCP Server and UDP profiles.
- Return transport-specific configuration and validate network ports and hostnames.
- Document network examples and existing transport limitations.

## 0.1.8 — Sequence management (2026-11-24)
- Add twelve data sequence management, execution and wait tools.
- Add independent sequence editing and execution permissions.
- Use existing SF sequence conversion and checksum generation.

## 0.1.7 — Project management (2026-11-24)
- Add eight .sflux project management MCP tools.
- Add separate project management and saving permissions.
- Protect unsaved changes and Save As overwrites.
- Update offline API documentation.

## 0.1.6 — Serial connection management (2026-11-23)
- Add serial connection creation, configuration, rename, delete and reconnect tools.
- Add ASCII escape handling, ASCII receive output and timed query.

## 0.1.5 — Version management (2026-11-23)

- Added sf_version_history MCP tool.
